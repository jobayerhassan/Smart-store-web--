# Smart Store

Responsive e-commerce frontend built with HTML, CSS and JavaScript.

## Run
Open `index.html` in any modern browser.

## Included
- Responsive homepage
- Search
- Category filtering
- Product sorting
- Add to cart
- Quantity controls
- Cart total
- Wishlist UI
- Login modal
- LocalStorage cart persistence
- Mobile responsive layout

This is a frontend demo. Login, database, real payment and admin features require a backend.
